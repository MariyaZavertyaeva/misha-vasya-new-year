# Новогодние приключения Миши и Васи 🎄

Личный новогодний сайт с мини-играми. **JUST FOR FUN.**

## Запуск

Откройте `index.html` в браузере. Установка Node.js не требуется.

## Структура

- `index.html` — главная страница, пока с заглушкой
- `games/olivier/` — Оливье Ninja
- `games/misha-tree/` — Миша и ёлка
- `games/vasya-crash/` — Вася и еда
- `fortune/` — кошачьи предсказания
- `assets/cats/` — фотографии котов
- `assets/pixel-art/` — графика
- `assets/audio/` — звук
- `css/` — общие стили
- `js/` — общая логика

## Публикация

Сайт статический и совместим с GitHub Pages. В настройках репозитория: **Settings → Pages → Deploy from a branch → main / (root)**.

Готовую афишу и игровые ассеты добавим позже. Сейчас никаких временных изображений нет.
